# Researcher reading framework

Use five internal tasks rather than one undifferentiated “summary” task.

## 1. Triage
Decide whether the paper deserves more time. Identify problem, real delta, strongest evidence, biggest risk, and reading priority.

## 2. Reconstruct
Rebuild the argument instead of following page order:

Problem → prior limitation → gap/bottleneck → core idea → design/argument → expected effect.

## 3. Verify
For each important claim, identify the strongest evidence, what it directly supports, what it only suggests, and the boundary of the conclusion.

## 4. Critique
Search for fragile assumptions, missing controls, alternative explanations, failure conditions, unfair comparisons, and generalization gaps. Prefer 2–4 consequential issues over many generic ones.

## 5. Transfer
Ask what should be carried forward: transferable mechanism, open question, validation opportunity, or source location worth close reading. Stop before automatically inventing a new named method.

The visible report does not need five new sections. Map these tasks into the stable six-stage report.
