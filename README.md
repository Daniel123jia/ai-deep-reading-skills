# PaperScope AI Deep Reading Skill

Codex skill for evidence-grounded academic paper deep reading in PaperScope.

## Contents

- `SKILL.md` - main workflow and boundaries.
- `references/evidence-rules.md` - evidence grading and wording rules.
- `schemas/deep-reading-result.schema.json` - structured output contract.
- `agents/openai.yaml` - agent metadata.

## Install

Copy this repository into:

```text
$CODEX_HOME/skills/paperscope-ai-deep-reading
```

Then use it when running AI paper deep reading, paper understanding, method analysis, claim-evidence review, or research follow-up workflows.
